# Claude Accountor 0.1.0 交付报告

日期：2026-11-05。交付为本机 macOS Apple Silicon 应用、源码及可重复执行的测试脚本。未发布到应用商店，未做 Apple Developer ID 签名或公证，未验证 Windows。

## 已实现

- 工作空间包含有序的多个本地项目；第一个项目为 CLI cwd，其余通过 `--add-dir` 加入。工作空间支持分组、置顶、搜索及最近使用排序。
- 按工作空间选择内置 xterm.js/node-pty 或真实 iTerm2 Python API。支持会话标签、Shell、分屏、历史恢复、外部终端定位；管理器重启不重复创建已有 iTerm2 会话。
- 左中右布局，右侧收缩、拖动调宽；文件树、Git 状态与变更摘要、CodeMirror 编辑、Markdown/JSON/CSV/图片预览。草稿持久化，外部写入冲突保护，异步保存期间继续输入不会丢失。
- 四个已授权入口引用现有配置，区分订阅与自定义模型；认证状态检查，登录及正常续期交由官方 CLI。网页登录只使用系统默认浏览器，启动环境和 CLI 设置均指定 macOS `/usr/bin/open`。
- 活动订阅账号从官方状态栏事件采集用量、窗口和时间。没有来源时显示未知，不把 Pro 额度伪装为美元余额，也不通过后台模型请求制造闲置账号实时刷新。
- 空闲时切换账号，保留原始记录与只读检查点。订阅账号双向及 ZMN 原始会话分支恢复通过；DP 默认使用可编辑交接预览，关闭该启动实例的工具搜索以兼容网关，原有启动脚本不修改。
- 浅灰、黑夜、跟随系统、本地背景图与 0–100% 图片不透明度；主题切换保持终端和草稿，背景移除不删除用户原图。

## 实现差异与边界

采用 Electron/React/TypeScript、xterm.js/node-pty 与原子 JSON，替代早期候选 Tauri/Rust/SQLite。iTerm2 是外部原生应用联动，不是画面嵌入。凭证保留在原 CLI 配置与系统凭证机制，安装包只收录程序和依赖，不收录账号、令牌或测试会话。

当前账号均已登录，因此没有触发真实浏览器 OAuth、验证码或过期凭证恢复；默认浏览器约束通过代码和环境测试验证，不能将其当作完整网页登录回归。续期由官方 CLI 执行，不承诺绕过官方交互或使失效授权永远自动恢复。

长对话压缩、所有附件/MCP 工具组合与所有网关版本没有穷尽验证；交接保留可见事实，不能恢复隐藏推理、服务端缓存或已结束进程。完整 IDE/LSP、Office/PDF/Mermaid 专用预览、跨设备同步及 Windows 属于后续扩展。当前 Git 面板提供状态和摘要，不包含完整图形化 Git 客户端。

安装包位于 `release/builds.noindex/Claude Accountor-darwin-arm64/Claude Accountor.app`，压缩分发包为 `release/Claude-Accountor-0.1.0-mac-arm64.zip`。可双击应用，也可将其复制到“应用程序”；运行真实会话需要本机 Claude CLI，iTerm2 模式还需要本机 iTerm2 和可用 Python。首次打开后可直接选工作空间并新建会话。

交付初始化状态：最终应用测试均使用隔离数据目录。向正式应用数据目录预导入四个入口的操作被自动审批服务额度耗尽拦截，未执行；因此首次运行请在“账号中心”导入已发现的四个本机入口，再创建工作空间。未打开正式应用窗口。该限制不影响已生成的应用和 ZIP，也不影响隔离环境中的最终安装包测试结果。

## 0.1.7 终端与导航集中修复（2026-11-05）

本轮用户问题及结果：

- `Accountor · 1%` 原来表示五小时已用比例。问题是启动时的额度采集命令替代了原 HUD 输出。现在读取各账号用户级 `statusLine`，将原始 JSON、账号环境及彩色/多行输出交给原命令，同时只保存额度元数据；原配置文件不改写。无 HUD 时采用明确标注“5h 已用”“本周剩余”的回退文本。HUD 失败、超时或额度文件写入失败不阻断 CLI。不会为了恢复 HUD 自动执行项目中未知的状态栏脚本。机制依据：[官方状态栏文档](https://code.claude.com/docs/en/statusline)。
- 终端标题栏增加 A− / 字号设置 / A+、回到底部与复制选区。设置支持 10–32px、系统等宽字体、Menlo、Monaco、Consolas 与 1–2 倍行高；字体变化重新适配行列，不重建 PTY。设置保存改为字段补丁，避免连续修改时被旧的整份设置覆盖。
- 修复 ⌘C：原生终端选区通过系统剪贴板复制；普通输入框仍使用原生 DOM 复制；无选区 Ctrl+C 仍交给 CLI。增加 OSC52 写剪贴板处理，不开放 CLI 读取剪贴板；CLI 全屏复制请求转发到对应复制动作。
