WbSpace 1.4.5。**安装包尚未签名/公证**：macOS 只有临时签名，Windows 没有 Authenticode，首次打开可能被系统拦截，请核对 SHA256SUMS.txt。

- 底部状态栏的“切换此会话账号”改为应用内下拉，按 Agent 工具分组，并直接标出每个账号的额度状态：五小时或本周剩余百分比（剩余不超过 10% 时变色）、额度用尽、需要登录、自定义模型或额度未知。额度来自上次刷新或会话中采集的数据，账号卡片的「刷新状态与用量」会更新。
