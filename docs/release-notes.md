WbSpace 1.2.0。**安装包尚未签名/公证**：macOS 只有临时签名，Windows 没有 Authenticode，首次打开可能被系统拦截，请核对 SHA256SUMS.txt。

- 系统提示词：在“设置 → 系统提示词”中添加多条自定义提示词，可单独启用、排序，并选择对哪些 Agent 生效。内容追加在 Claude Code、Codex CLI、Qoder CLI、OpenCode 自带的系统提示词之后，不替换原有内容；对新开、恢复和定时任务的会话生效。
- Windows：npm、pnpm、yarn 安装的 Codex、OpenCode 等 `.cmd` 入口改为直接启动背后的实际程序，不再经过 `cmd.exe`。系统提示词、定时任务提示词和接力提示中的引号、`%`、`^`、`&`、`<`、`>`、换行都能原样传入，此前这些提示词会被拒绝或被截断。
- Windows：仍需经 `cmd.exe` 启动时，含 `&`、`<`、`>`、`|` 的参数会加引号，避免被当作命令或重定向执行。
- Windows：参数改用标准规则转义，整段用引号括起来的提示词不再被拆成多个参数。
- 1.0.x、1.1.x 可在设置中点击检查更新直接升级；0.4.x 及更早版本需手动安装一次本版本。

下载后先核对 SHA256SUMS.txt。macOS 首次打开需在隐私与安全性中确认“仍要打开”；Windows 可能出现未知发布者提示；企业设备策略可能禁止运行。
