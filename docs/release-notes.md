WbSpace 1.3.2。**安装包尚未签名/公证**：macOS 只有临时签名，Windows 没有 Authenticode，首次打开可能被系统拦截，请核对 SHA256SUMS.txt。

- 修复：应用内更新或退出应用后，正在运行的会话从会话列表中消失（1.2.1 起）。退出时结束的内置终端现在记为“已中断”，重启后仍在列表中，可以恢复；运行中的定时任务记为“应用退出时中断”。
  - 此前因此隐藏的会话无法自动区分是否为手动结束，不会自动找回；对话记录仍在账号目录中。
- 1.0.x 至 1.3.1 可在设置中点击检查更新直接升级；0.4.x 及更早版本需手动安装一次本版本。

下载后先核对 SHA256SUMS.txt。macOS 首次打开需在隐私与安全性中确认“仍要打开”；Windows 可能出现未知发布者提示；企业设备策略可能禁止运行。
