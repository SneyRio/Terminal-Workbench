WbSpace 1.1.0。**安装包尚未签名/公证**：macOS 只有临时签名，Windows 没有 Authenticode，首次打开可能被系统拦截，请核对 SHA256SUMS.txt。

- 定时任务：按间隔、每天、每周或 cron 表达式，让任意 Agent 账号无人值守地执行提示词。默认只读；允许修改文件的任务在独立 Git 工作树和新分支中运行，不影响当前工作区。会自动跳过重叠运行、额度将尽和需要重新登录的账号，支持超时、补跑和系统通知。仅在应用运行时执行。
- 会话可切换到任意 Agent 的任意账号继续（Claude、Codex、OpenCode、Qoder），跨 Agent 时通过交接资料接力。
- 无工作空间会话：侧边栏新增固定入口，会话在 `~/wbspace` 中启动。
- Git 面板：分支列表与切换，暂存、提交、推送和拉取。底部状态栏显示当前分支。
- 会话名称改为 `[agent]名称`，不再包含账号名。
- CLI 路径设置移到 Agent 管理页。
- 1.0.x 可在设置中点击检查更新直接升级；0.4.x 及更早版本需手动安装一次本版本。

下载后先核对 SHA256SUMS.txt。macOS 首次打开需在隐私与安全性中确认“仍要打开”；Windows 可能出现未知发布者提示；企业设备策略可能禁止运行。
