WbSpace 1.4.0。**安装包尚未签名/公证**：macOS 只有临时签名，Windows 没有 Authenticode，首次打开可能被系统拦截，请核对 SHA256SUMS.txt。

- 新增 Claude 对话界面：Claude 会话默认以类似 Claude Desktop 的对话界面打开。底层仍是同一个 Claude Code CLI，系统提示词、工具、CLAUDE.md、skills、hooks、插件、子代理和 MCP 都不变；对话记录与终端共用，可随时在面板右上角切到终端继续同一段对话，再切回来。
  - 流式回复、Markdown 与代码高亮；工具调用显示为卡片，带耗时；每条消息显示时间。
  - 权限确认、`AskUserQuestion` 选项、计划审批都在卡片上完成，不会自动批准。权限模式为自动（默认）、计划、YOLO，可随时切换；模型可切换，默认“默认模型”。切换界面或换账号后，模式和模型保持不变。
  - 子代理卡片显示耗时、工具调用次数和 token 用量，可在右侧打开详情查看任务、每一步和返回结果，详情宽度可拖动调整；后台运行的子代理同样跟踪到结束。
  - 图片可粘贴或拖入，消息中显示缩略图，点击放大预览。
  - `/` 命令补全；`/btw <问题>` 旁路提问：基于当前对话快速回答，不打断任务、不使用工具、不写入对话历史（会读取一次上下文，消耗额度）。
  - 额度在对话过程中实时更新到底部状态栏；换账号接力照常可用。
  - 设置 → “Claude 会话界面”可改回终端；已有会话保持原界面。仅 Claude Code 账号支持对话界面，Codex、Qoder、OpenCode 仍用终端。
- Windows：结束对话会话时连同其 MCP 服务器和命令进程一起结束。对话界面在 Windows 上尚未经过真实账号验证，遇到问题可在面板右上角切回终端。
- 1.0.x 至 1.3.2 可在设置中点击检查更新直接升级；0.4.x 及更早版本需手动安装一次本版本。

下载后先核对 SHA256SUMS.txt。macOS 首次打开需在隐私与安全性中确认“仍要打开”；Windows 可能出现未知发布者提示；企业设备策略可能禁止运行。
