WbSpace 1.4.3。**安装包尚未签名/公证**：macOS 只有临时签名，Windows 没有 Authenticode，首次打开可能被系统拦截，请核对 SHA256SUMS.txt。

- 修复：退出或更新应用后恢复会话，最近的对话不见了，会话回到较早的内容。Claude CLI 恢复会话时可能改用新的会话文件继续记录，并在旧文件末尾留下 `continued-in` 标记，但退出时上报的 `SessionEnd` 仍带旧会话 ID，应用据此把会话改回了旧文件。现在会话始终跟随 `continued-in` 指向最新的记录；恢复会话、切换账号和删除时保存的检查点都使用最新记录。
  - 启动时自动修正此前已指向旧记录的会话（包括最近删除中的会话），对话内容本身一直保留在账号目录中。
- 修复：退出或更新时，状态文件的最后一次写入可能被中途打断。现在退出前等待所有写入完成，之后不再开始新的写入。
- 1.0.x 至 1.4.2 可在设置中点击检查更新直接升级；0.4.x 及更早版本需手动安装一次本版本。本次修复从下一次退出起生效：从旧版本更新时那一次退出仍由旧版本执行，新版本启动后会修正受影响的会话。

下载后先核对 SHA256SUMS.txt。macOS 首次打开需在隐私与安全性中确认“仍要打开”；Windows 可能出现未知发布者提示；企业设备策略可能禁止运行。
