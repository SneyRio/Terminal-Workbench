- 修复：应用内更新或退出应用后，正在运行的会话仍会从会话列表消失（1.3.2 的修复未生效）。Claude CLI 退出时通过钩子上报的 `SessionEnd` 会抢先把会话记为“已结束”；现在退出和更新期间结束的会话一律记为“已中断”，重启后可以恢复。退出时也会等会话状态写入完成再关闭应用。

- 对话界面按 Esc 打断不再要求光标在输入框内：焦点在对话面板任意位置均可，仍先关闭 `/btw` 回答和详情面板。
- 深色主题下代码块的普通文本、命令、变量等几乎看不清，现已补全深色配色，代码块内边距也不再重复叠加。
- 1.0.x 至 1.4.0 可在设置中点击检查更新直接升级；0.4.x 及更早版本需手动安装一次本版本。
