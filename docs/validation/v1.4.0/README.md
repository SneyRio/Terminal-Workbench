## 对话界面（真实 Claude CLI 2.1.322，macOS）

`scripts/chat-native-smoke.mjs` 用真实账号（jemusbob，接力到 tomton）在应用内跑完 11 步，全部通过：

1. 新建 Claude 会话默认打开对话界面。
2. 未发消息的会话切换界面：原位重新启动，不报恢复失败。
3. 项目 CLAUDE.md 生效、流式回复；发送的消息 1 秒内显示且只出现一次。

6. `AskUserQuestion` 在卡片上回答并传回。

9. 切到终端继续同一段对话。
10. 切回对话界面，历史完整，模型选择保持。
11. 切换到另一账号后仍为对话界面，历史完整并可继续对话。
