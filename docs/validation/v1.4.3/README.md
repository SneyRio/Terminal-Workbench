## 单元测试覆盖

- 没有 `continued-in` 时不变；多次续接跟到最后一个；旧文件在标记之后还有记账行时仍能识别。
- 续接到其他项目目录时通过查找定位；目标缺失时停在当前文件。
- 删除时保存的检查点副本指向账号目录中的最新记录。
- 循环引用、损坏行、非法会话 ID 不会导致卡死或越界。
- 状态写入：`drain()` 等待等待期间新排入的写入；`close()` 后拒绝写入且不改动文件。
